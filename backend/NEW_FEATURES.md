# Новые фичи канала @nowicki_news

## 1. Обзор рынка (Market Digest)

**Файл**: `backend/market_digest.py`

### Что делает:
- Утренний (09:00 Kyiv) и вечерний (21:00 Kyiv) обзор рынка
- Общий фон: BTC, альты, доминация, настроение
- Без конкретных входов — просто взгляд на рынок
- Голос первого лица, 200-300 символов

### Настройки (env):
- `MARKET_DIGEST_ENABLED=1` — вкл/выкл (default: 1)
- `DIGEST_MORNING_HOUR=9` — час утреннего обзора (default: 9)
- `DIGEST_EVENING_HOUR=21` — час вечернего обзора (default: 21)

### Расписание:
- **Автоматически**: каждые 1 час проверяет расписание, постит с random delay 10-30 мин от целевого часа
- **Вручную**: POST `/api/digest/trigger` с `{"time_of_day": "morning"}` или `{"time_of_day": "evening"}`

### Пример поста:
```
🌅 Утренний взгляд

BTC держится в 64-65k, альты спокойные. Доминация 53% — пока боковик.
Сегодня данные по инфляции из US, жду реакцию к вечеру. Пока без резких движений.
```

## 2. Еженедельная статистика (Weekly Stats)

**Файл**: `backend/weekly_stats.py`

### Что делает:
- Раз в неделю (воскресенье, 20:00 Kyiv) — итоги недели
- Сколько сигналов, win rate, лучшие сетапы
- **С приукрашиванием**: если неделя слабая — берёт 14 или 30 дней для лучших цифр
- Тон позитивный, ошибки признаём честно

### Настройки (env):
- `WEEKLY_STATS_ENABLED=1` — вкл/выкл (default: 1)
- `STATS_HOUR=20` — час публикации (default: 20)

### Расписание:
- **Автоматически**: каждые 6 часов проверяет, постит если воскресенье + час подходит + не постили за 5 дней
- **Вручную**: POST `/api/stats/trigger`

### Пример поста:
```
📊 Итоги недели

За неделю отработал 7 сигналов — 5 в профите, 2 по стопу. Средний +4.2% на позу.
Лучший сетап: SOL long от зоны спроса, забрал +8.5%. BTC short не зашёл — рынок развернулся.
В целом неделя рабочая, доволен дисциплиной.
```

## 3. Важные новости

**Файл**: `backend/telegram_bot.py`

### Что делает:
- Команда `/news` для админов → публикация важной новости в канал
- Формат: `/news Текст новости (факт + влияние на рынок)`

### Пример:
```
/news SEC одобрила ETF на ETH — ждём приток капитала в альты
```

Публикуется как:
```
📰 SEC одобрила ETF на ETH — ждём приток капитала в альты
```

---

## Как всё работает:

1. **Автозапуск**: `main.py` добавляет `market_digest.run()` и `weekly_stats.run()` в фоновые задачи
2. **Daemon loops**: каждый модуль крутит свой цикл, проверяет расписание, постит если пора
3. **Human-like delay**: не постим ровно в 09:00, а +10-30 мин (random)
4. **Anti-duplicate**: проверяем timestamp последнего поста, не дублируем

## Тестирование:

### Утренний обзор СЕЙЧАС:
```bash
cd backend
python _direct_morning.py
```

### Вечерний обзор СЕЙЧАС:
Изменить `"morning"` на `"evening"` в `_direct_morning.py`

### Еженедельная статистика СЕЙЧАС:
POST `/api/stats/trigger` или через Railway API

## Deployment:

Уже задеплоено на Railway. После `railway up` фоны стартуют автоматически.

Проверить логи:
```bash
railway logs
```

Должно быть:
```
[market_digest] start → @nowicki_news morning=9:00 evening=21:00
[weekly_stats] start → @nowicki_news Sunday 20:00
```
