# Post & Comment Review System

Автоматическая проверка качества постов и комментариев с AI-анализом на баги, несостыковки и стиль.

## 🎯 Возможности

### 1. **Проверка комментариев** (уже работает)
Анализирует комменты фермы на штампы, дубликаты, bot-like поведение.

**Модель:** Claude Sonnet 4.5  
**Стоимость:** ~$0.018 за проверку 80 комментариев (~1.8₽)

**Запуск:**
```bash
# Из scaner/
py -3 scripts/review_farm_comments.py --hours 48 --limit 100
py -3 scripts/review_farm_comments.py --notify  # отправит итог в Saved Messages
```

### 2. **Проверка постов** (новое)
Глубокий анализ постов market_outlook на:
- Противоречия цены vs прогноз
- Логические несостыковки
- AI-штампы и канцелярит
- Несовместимость текста с графиком (мультимодальный анализ)
- Проблемы с trust и честностью прогнозов

**Модели:**
- **Fast mode** (Gemini Flash): $0.01 за проверку 30 постов
- **Deep mode** (Gemini 3.1 Pro): $0.03 за проверку 20 постов + графики (~3₽)
- **Deep mode** (Claude Sonnet 4.5): лучше для стиля на русском
- **Deep mode** (GPT-5.5 Pro): лучше для логических противоречий

**Запуск:**
```bash
# Из crypto-signal-app/
py backend/post_review.py --mode fast --hours 24
py backend/post_review.py --mode deep --hours 12 --model gemini
py backend/post_review.py --mode deep --model claude  # для стиля
py backend/post_review.py --auto  # loop: fast каждые 6ч, deep каждые 24ч
```

## 📊 Что проверяется

### Fast Review (Gemini Flash)
✅ Противоречия цены (пост говорит 64500, а контекст 58000)  
✅ Логические несостыковки (long-сценарий с целью ниже текущей)  
✅ Опасные штампы AI («важно отметить», «следовательно»)  
✅ Дублирование контента  
✅ Обещания без hedge («точно пойдет», «гарантирую»)

### Deep Review (Gemini 3.1 Pro / Claude / GPT)
✅ Логика прогноза (причина → следствие, инвалидация)  
✅ Профессиональность стиля (живой трейдер vs AI-генератор)  
✅ Честность прогноза (можно ли уличить в подтасовке?)  
✅ Разнообразие (все по шаблону или уникально?)  
✅ **Мультимодальный анализ** (текст + график вместе, только Gemini)  
✅ Update-посты (адекватность результата, честность при сломе)

## 📁 Отчёты

Все отчёты сохраняются в:
- Комменты: `scaner/data/comment_reviews/`
- Посты: `crypto-signal-app/data/post_reviews/`

Форматы: JSON (полный) + Markdown (читаемый)

**Быстрый доступ:**
- `latest.json` / `latest.md` — последний отчёт
- `latest_fast.json` / `latest_deep.md` — последние по типу

## 🔧 Настройка моделей

### Для комментариев
Редактируй `scaner/telegram_client/comment_review.py`:
```python
model=settings.openai_model or "anthropic/claude-sonnet-4.5"
```

### Для постов
По умолчанию:
- Fast: `google/gemini-2.5-flash`
- Deep: `google/gemini-3.1-pro-preview` (мультимодальный)

Меняй через `--model`:
- `--model gemini` — мультимодальный анализ (текст + график)
- `--model claude` — лучший стиль на русском
- `--model gpt` — сильнейшее reasoning для логики

## 🚀 Автоматизация

### Добавить в Railway / systemd
```bash
# Auto-loop для постов (fast каждые 6ч, deep каждые 24ч)
py backend/post_review.py --auto

# Для комментариев — cron или while-loop:
while true; do
  py -3 scripts/review_farm_comments.py --hours 12
  sleep 21600  # 6 часов
done
```

### Webhook в Telegram (опционально)
Можно отправлять отчёты в приватный канал/чат:
```python
# В конце _run_review():
if review.get("score_1_10") and review["score_1_10"] < 6:
    # Отправить алерт в Telegram
    await bot.send_message(ADMIN_CHAT_ID, f"⚠️ Low score: {review['summary']}")
```

## 📈 Интеграция с бустером

Результаты проверки можно использовать для:
1. **Авто-бан фраз** — добавлять `banned_phrases_add` в `channel_booster.py`
2. **Улучшение промптов** — применять `prompt_tweaks` к `COMMENT_PROMPT`
3. **Мониторинг дрейфа** — если score падает → модель деградирует, нужна коррекция

## 🎓 Как выбрать модель

| Задача | Модель | Почему |
|--------|--------|--------|
| Комменты на русском | Claude Sonnet 4.5 | Лучший баланс стиля/цены для RU |
| Посты + график | Gemini 3.1 Pro | Единственный мультимодальный по приемлемой цене |
| Стиль и тон | Claude | Чище держит RU тон, видит нюансы |
| Логика и противоречия | GPT-5.5 Pro | Сильнейшее reasoning (дорого) |
| Массовая проверка | Gemini Flash | Дешево и быстро для первого фильтра |

## ⚠️ Важно

1. **OpenRouter API Key** — нужен в `.env`:
   ```
   OPENAI_API_KEY=sk-or-v1-...
   OPENAI_BASE_URL=https://openrouter.ai/api/v1
   ```

2. **База данных** — для постов нужна схема БД с таблицей `posts` или `settings.outlook_recent_posts`. Если её нет, система возьмёт данные из `_SETTING_RECENT`.

3. **Графики** — для мультимодального анализа нужны PNG-файлы в `static/charts/`. Gemini автоматически подхватит последний график для каждого символа.

4. **Кеширование** — OpenRouter автоматически кеширует повторяющийся контекст (system prompt, примеры), что снижает цену на 40-60%.

## 🐛 Troubleshooting

**Q: "parse_error: True" в отчёте**  
A: Модель вернула не JSON. Увеличь `max_tokens` или упрости промпт.

**Q: "AI выключен" в отчёте**  
A: Проверь `.env` — должны быть `AI_ENABLED=1` и `OPENAI_API_KEY`.

**Q: Мультимодальный режим не работает**  
A: Убедись что:
- Используешь `--model gemini`
- Графики существуют в `static/charts/`
- Модель = `google/gemini-3.1-pro-preview` (не flash)

**Q: Дорого**  
A: Используй только fast-режим (Gemini Flash) или уменьши частоту проверок.
