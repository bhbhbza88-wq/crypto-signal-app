# BingX Win Card Template

Template for closed positions in profit.

Key features:
- Black background
- Blue/yellow Doge character with green cap
- "Unrealized PnL" header (or "Нереализованная П/У")
- Symbol, side (Short/Long), leverage displayed
- Large PnL percentage in green
- "Last Price" (exit price)
- "Entry Price" 
- User ID/date and referral code in footer

Style: BingX black background, suitable for wins
